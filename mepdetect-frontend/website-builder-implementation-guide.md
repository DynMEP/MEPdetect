> Do NOT publish testimonials, customer names, logos, star ratings or
> "trusted by N customers" figures until they are real, attributable and
> consented to in writing. Fabricated endorsements are deceptive advertising
> under the FTC Endorsement Rule (16 CFR Part 465) and carry civil penalties.
> Use the live demo below as social proof instead — it is verifiable.

### Section Header:
```
Title: See It on Your Own Drawing
Subtitle: No sign-up, no sales call. Upload a sheet and read the output yourself.
```

### Upload Card:
```
Heading: Drop an electrical, HVAC or plumbing sheet here
Body: PDF, JPG, PNG or TIFF — up to 50 MB. Processed in seconds.
Button: Run a Live Detection
```

### Output Card ("What comes back"):
```
- Annotated sheet — every detection boxed and labeled, so you can check the count against the drawing yourself.
- Symbol counts — one row per symbol type, with the per-detection confidence score.
- Coordinates — bounding box and centroid for each detection, in image pixels.
- Circuit netlist — traced conductor runs, junction nodes, homerun arrows and the devices grouped onto each circuit.
- Files — JSON, CSV and Excel, ready to drop into your estimating spreadsheet.

Note: Detection quality depends on the drawing: line weight, scan resolution
and how close your symbols are to the ones the model was trained on. Run it on
your own sheets before you rely on it for a bid.
```

## ❓ FAQ SECTION

### Section Header:
```
Title: Frequently Asked Questions
```

### FAQ 1:
```
Question: How accurate is the AI symbol detection?
Answer: MEPdetect achieves 95%+ accuracy on standard MEP symbols using state-of-the-art YOLO11 object detection. For custom symbols, you can train the AI on your specific drawings to achieve even higher accuracy. The system continuously learns and improves with use.
```

### FAQ 2:
```
Question: What file formats do you support?
Answer: We support PDF files (including multi-page plan sets), as well as common image formats including JPG, PNG, TIFF, and BMP. Whether you have scanned paper drawings, digital PDFs, or CAD exports, MEPdetect can process them. We recommend 300-400 DPI for best results with scanned documents.
```

### FAQ 3:
```
Question: Can I train the AI on my company's custom symbols?
Answer: Yes! Professional and Enterprise plans include custom symbol training. Simply upload 20-50 labeled examples of your symbols, and our AI will learn to detect them. This is perfect for specialized equipment, company-specific CAD blocks, or non-standard fixtures. Training typically takes 1-3 hours.
```

### FAQ 4:
```
Question: How does MEPdetect integrate with my existing workflow?
Answer: MEPdetect exports to Excel, CSV, and JSON formats that work seamlessly with popular estimating software like ConEst, Accubid, and McCormick. Professional and Enterprise plans include direct integration with BIM platforms like Revit and AutoCAD. You can also use our API to build custom integrations.
```

### FAQ 5:
```
Question: Is my project data secure and private?
Answer: All drawings are encrypted in transit (TLS) and at rest. We never share your data with third parties, and you maintain full ownership of all uploaded files and results. Enterprise plans can be deployed on-premise, so your drawings never leave your network. We are not currently SOC 2 audited — if your procurement process requires it, contact us and we will tell you exactly where we stand.
```

## 🔧 SQUARESPACE SPECIFIC TIPS

1. **Use Index Page Structure**: Each section as a separate page in index
2. **Enable Parallax**: On hero section background for visual interest
3. **Summary Blocks**: Use for blog/case study previews
4. **Form Block**: For "Contact Sales" and demo requests
5. **Accordion Block**: Perfect for FAQ section
6. **Button Blocks**: For all CTAs, not text links

### Recommended Squarespace Templates:
- **Farro**: Clean, modern, great for SaaS
- **Bryant**: Professional, good typography
- **Bailey**: Bold, impact-focused
- **Skye**: Modern, conversion-optimized

## 🎯 CARRD SPECIFIC TIPS

1. **Use Carrd Pro Plus**: For custom domains and more sections
2. **Container Widths**: Set to "Medium" (960px) for readability
3. **Background Images**: Use subtle gradients, not photos
4. **Button Links**: Use #pricing format for anchor links
5. **Font Loading**: Stick to system fonts or Google Fonts
6. **Mobile Optimization**: Test on phone view constantly

### Carrd Section Types to Use:
- Hero: Header + Big Text + Buttons
- Features: Grid (3 columns) with Icons + Text
- Pricing: Pricing Table (3 columns)
- Live demo: 2-column Grid
- FAQ: Collapsible List
